# Database Cleanup Scripts

These scripts help you clear old "junk" signals generated by the previous signal engine before the Institutional Signal Engine V2.0 was implemented.

## Scripts

### 1. Clear ALL Signals (`clearOldSignals.ts`)

**Deletes everything** - all signals and accuracy records.

```bash
cd backend
npx ts-node src/scripts/clearOldSignals.ts
```

**What it does:**
- Deletes all SignalAccuracy records
- Deletes all Signal records
- Shows before/after counts

**Use this when:**
- You want to start completely fresh
- All existing signals are from the old system
- You want a clean slate for the new institutional engine

---

### 2. Clear Signals Before Date (`clearOldSignalsBeforeDate.ts`)

**Selectively deletes** - only signals created before a specific date.

```bash
# Delete signals before today
cd backend
npx ts-node src/scripts/clearOldSignalsBeforeDate.ts

# Delete signals before a specific date
CUTOFF_DATE="2025-01-15" npx ts-node src/scripts/clearOldSignalsBeforeDate.ts
```

**What it does:**
- Deletes signals created BEFORE the cutoff date
- Keeps signals created ON or AFTER the cutoff date
- Deletes associated accuracy records

**Use this when:**
- You want to keep some recent signals
- You know the exact date you deployed the new engine
- You want more control over what's deleted

## Safety Notes

⚠️ **These scripts permanently delete data!**

- There is **no undo** - once deleted, data cannot be recovered
- Consider backing up your database first:
  ```bash
  # PostgreSQL backup example
  pg_dump $DATABASE_URL > backup_before_cleanup.sql
  ```

- Test in development first
- Make sure you understand what will be deleted

## Why Clean Up?

The old signal engine had these issues:
- ❌ Meaningless confidence scores (42-60% on everything)
- ❌ Unrealistic targets (80%+ away from price)
- ❌ Signal spam (50+ per hour)
- ❌ No institutional filtering
- ❌ No chop suppression

The new Institutional Signal Engine V2.0:
- ✅ Real confidence scores (65-90%, or rejected)
- ✅ ATR-based realistic targets (2-5% away)
- ✅ Quality over quantity (3-5 per hour)
- ✅ 5-pillar institutional scoring
- ✅ Chop suppression (80% during sideways markets)

**Starting fresh ensures your database only contains high-quality institutional-grade signals.**

## After Cleanup

Once you've cleaned up the old signals:

1. **Restart your backend** to ensure the new engine is active
2. **Wait for market hours** (9:30 AM - 4:00 PM ET)
3. **Monitor the logs** for new signal generation
4. **Expect 3-5 signals per hour** (not 50+)
5. **Check confidence scores** are 65%+ (not 42-60%)

The new engine will start generating fresh, institutional-grade signals automatically during market hours (every 5 minutes).
